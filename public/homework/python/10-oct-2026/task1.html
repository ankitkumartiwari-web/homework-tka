Student Class — Task 1

Practice creating a class, storing object attributes, and displaying the details of multiple students.

Assignment

  1. Create a Student class with name, roll_no, and course attributes.
  2. Create a display_student() method that prints all student details.
  3. Create at least two Student objects with different values.
  4. Call display_student() for both objects.
  5. Bonus: Add an email attribute and display it.

Solution

class Student:
    def __init__(self, name, roll_no, course, email):
        self.name = name
        self.roll_no = roll_no
        self.course = course
        self.email = email

    def display_student(self):
        print(f"Name: {self.name}")
        print(f"Roll No: {self.roll_no}")
        print(f"Course: {self.course}")
        print(f"Email: {self.email}")
        print()


student_one = Student(
    "Rahul",
    101,
    "Python Full Stack",
    "rahul@example.com",
)
student_two = Student(
    "Priya",
    102,
    "Data Science",
    "priya@example.com",
)

student_one.display_student()
student_two.display_student()

Output

Name: Rahul
Roll No: 101
Course: Python Full Stack
Email: rahul@example.com

Name: Priya
Roll No: 102
Course: Data Science
Email: priya@example.com
