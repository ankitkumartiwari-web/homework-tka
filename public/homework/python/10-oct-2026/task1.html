Task 3: Scenario: Build a simple bank account system. Your Task: • Create a BankAccount class with account_number, holder_name and balance. • Initialize the values using __init__(). • Create deposit(amount) to add money. • Create withdraw(amount) to subtract money only when sufficient balance is available. • Create check_balance() to display the current balance. • Test deposit and withdrawal operations. Expected Output (example): Initial Balance: 10000 Deposited: 3000 Withdrawn: 2500 Current Balance: 10500 Bonus Challenge: Add a transaction_history list and store every deposit/withdrawal.
Code
class BankAccount:
    def __init__(self, account_number, account_holder, balance):
        self.account_number = account_number
        self.account_holder = account_holder
        self.balance = balance

    def deposit(self, amount):
        amount = float(amount)
        if amount > 0:
            self.balance += amount
            print(f"Deposited: {amount} \nNew Balance: {self.balance}")

    def withdraw(self, amount):
        amount = float(amount)
        if amount > 0 and amount <= self.balance:
            self.balance -= amount
            print(f"Withdrawn: {amount} \nNew Balance: {self.balance}")
        else:
            print("Insufficient balance or invalid amount.")

    def check_balance(self):
        print(f"Account Holder: {self.account_holder} \nAccount Number: {self.account_number} \nBalance: {self.balance}")

Task 6: Scenario: Build a small employee management system using OOP concepts. Your Task: • Create a parent class Employee with employee_id, name and salary. • Create Developer(Employee) with programming_language. • Create Tester(Employee) with testing_tool. • Use constructors in all classes. • Implement display_info() in the parent class. • Override display_info() in Developer and Tester to include role-specific information. • Create at least two developers and two testers. • Store all objects in a list and iterate through the list to display their details. Expected Output (example): The output should clearly identify each employee's ID, name, salary and role-specific information. Bonus Challenge: Add Manager(Employee) with a team_size attribute. Add a method to calculate annual salary.
Code
class Employee:
    def __init__(self, employee_id, name, salary):
        self.employee_id = employee_id
        self.name = name
        self.salary = salary

    def calculate_annual_salary(self):
        return self.salary * 12

    def get_role(self):
        return "Employee"

    def get_role_details(self):
        return "-"

    def display_info(self):
        print(
            f"| {self.employee_id:<11} "
            f"| {self.name:<12} "
            f"| {self.salary:<10.2f} "
            f"| {self.calculate_annual_salary():<13.2f} "
            f"| {self.get_role():<10} "
            f"| {self.get_role_details():<20} |"
        )


class Developer(Employee):
    def __init__(self, employee_id, name, salary, programming_language):
        super().__init__(employee_id, name, salary)
        self.programming_language = programming_language

    def get_role(self):
        return "Developer"

    def get_role_details(self):
        return self.programming_language


class Tester(Employee):
    def __init__(self, employee_id, name, salary, testing_tool):
        super().__init__(employee_id, name, salary)
        self.testing_tool = testing_tool

    def get_role(self):
        return "Tester"

    def get_role_details(self):
        return self.testing_tool


class Manager(Employee):
    def __init__(self, employee_id, name, salary, team_size):
        super().__init__(employee_id, name, salary)
        self.team_size = team_size

    def get_role(self):
        return "Manager"

    def get_role_details(self):
        return f"Team size: {self.team_size}"


employees = [
